# VitalSign AI — ICU Mortality Risk Predictor

A clinical decision-support tool that estimates ICU hospital-mortality risk from bedside vitals, labs, and APACHE features. Features an Apple-minimal interface designed for intensivists at the point of care.

---

## Quick Start

### 1. Install Dependencies

```bash
pip install -r requirements.txt
```

### 2. Train the Model

```bash
python train_model.py
```

This generates synthetic ICU patient data and trains a Gradient Boosting classifier. The model is saved to `model/mortality_model.pkl`.

### 3. Run Locally

```bash
python app.py
```

Open **http://localhost:5000** in your browser.

---

## Deploy to Vercel

### 1. Install Vercel CLI

```bash
npm i -g vercel
```

### 2. Deploy

```bash
vercel
```

Follow the prompts. The project is pre-configured via `vercel.json` to:
- Serve the UI at `/`
- Handle predictions at `/api/predict` and `/api/predict_batch`
- Serve static assets from `/static/`

## API Endpoints

| Method | Path                | Description                    |
|--------|---------------------|--------------------------------|
| GET    | `/`                 | Prediction UI                  |
| POST   | `/api/predict`      | Single-patient JSON prediction |
| POST   | `/api/predict_batch`| Batch CSV prediction           |
| GET    | `/api/health`       | Liveness check                 |

Upload a CSV file via multipart form with the `file` field. Column headers must match the feature names above.

## Risk Bands

| Band      | Probability Range | Color  |
|-----------|-------------------|--------|
| Low       | < 0.15            | Green  |
| Moderate  | 0.15 – 0.35       | Amber  |
| High      | 0.35 – 0.70       | Orange |
| Critical  | >= 0.70           | Red    |
