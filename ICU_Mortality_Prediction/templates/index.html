Why this model works

The predictor is an XGBoost classifier trained on the MIT/GOSSIS ICU dataset. It combines a small set of high-signal APACHE features with tested/untested flags for optional labs.

Calibrated probabilities

Output is a 0–1 probability, not a hard label — clinicians see the actual risk instead of a black-box verdict.

Handles missing labs

Optional labs (lactate, pH, albumin) carry an explicit tested indicator, so absent tests are informative instead of imputed away.

Tree-based & robust

Gradient-boosted trees tolerate outliers, mixed scales, and interactions between vitals and comorbidities without heavy preprocessing.

Threshold-aware

A tuned decision threshold (0.35) trades recall for precision in favor of catching high-risk patients earlier.

Transparent inputs

Every input is a bedside-recorded variable — no hidden embeddings, no opaque IDs. Auditable end to end.

Fast at the bedside

Single-patient inference completes in milliseconds; batch CSV scoring runs offline on the same Flask service.

About VitalSign AI

Built to accompany the ICU Mortality Prediction notebook, VitalSign AI packages the trained model behind a minimal Flask API and a clean interface, so bedside teams and researchers can explore predictions without touching Python.

For clinicians

Enter the values you already track on rounds and get a calibrated risk band. Use it as a second opinion, never a substitute for judgment.

For data teams

Drop in a new .pkl and the same UI serves it. Batch mode lets you re-score cohorts or validate on held-out CSVs.
